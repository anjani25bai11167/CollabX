# CollabX – Project Collaboration Platform

## Problem Statement

Students have project ideas but lack potential teammates with the needed skills, interests, and availability. Additionally, there is no readily accessible platform for students to find projects and opportunities that match their skill set and availability.

The CollabX Project Collaboration Platform will offer a streamlined process of creating projects, discovering existing projects, discovering one’s opportunities, applying to join teams, and working through organized task management.

This project aims to provide a convenient solution for student project collaboration while prioritizing skills and interests.

## Scope

The CollabX projectscope encompasses developing a student project collaboration platform and the essential features involved in the project creation process, finding opportunities, applying, and managing tasks. The following features will be included:

• User registration, login, and profile creation

• Skills and user profile management

• Project creation and management

• Searching for projects by title, category, description, and skills
• Finding projects that match one’s skills

• Applying to join a project
• Project application management, including viewing and accepting applications

• Creating project teams
• Creating, viewing, and managing tasks
• Viewing project team members and the tasks
• Managing tasks and their deadlines
As a prototype, the initial version of the application will be developed as a Java console application. In the future, the prototype will be enhanced by adding a graphical user interface, connecting the application to a database, implementing notification and messaging features, and enabling GitHub collaboration. Additionally, extra features such as improved recommendation algorithms and advanced search filters can be added.

## Target Users
### 1. Students
Students will be able to:
• Register and log in to the application
• Update their profiles and add their skills
• Discover existing projects
• Apply to join projects
• Collaborate on projects by completing assigned tasks

### 2. Project Creators/Student Team Leaders
These students will be able to:
• Create projects and set the required skills
• Set the team size and view applications
• Accept applications from suitable candidates
• View and manage their project tasks

### 3. Academic Project Teams
Student teams will be able to collaborate on projects by managing tasks.

## High-Level Features

### 1. User Management
This feature entails user registration, logging in, and updating user profiles. The following will be included:
• User registration
• Logging in and out of the application
• Updating the profile
• Managing one’s skills
• Entering one’s course(s)

### 2. Project Management
The project management feature enables students to create a project. The following functions will be available:
• Create new projects
• Entering project titles and descriptions
• Selecting the project category
• Entering the skills needed
• Setting the team size
• View project status, including the number of team members

### 3. Project Search
Using this feature, students will be able to find existing projects using the following criteria:
• Browse existing projects
• Search for projects by title
• Filter projects by category
• Filter projects by required skills
• Search using the project description

### 4. Skill Matching
The application will compare the user’s skills against those needed for a project and calculate the percentage of skill match.
Percentage match = (Number of matching skills / Number of skills needed) × 100%

### 5. Project Applications
Through this feature, users can apply to join a project. The following functions will be available:
• Apply to join a project
• Entering a message to the project creator
• Viewing applications
• Avoiding duplicate applications
• Managing applications
• Accepting applications

### 6. Team Management
The team management feature enables the project creator to add team members to a project. The following functions will be available:
• Add the project creator to the team
• Add suitable applicants to the project team
• Limit the number of team members based on the set team size
• View the skills of each team member

### 7. Task Management
The task management feature allows project team members to set and manage tasks. The following functions will be available:
• Set tasks
• Assign tasks to specific team members
• Set task deadlines
• View tasks
• Update task status
• View project tasks

### 8. Input Validation and Error Messages
This feature entails ensuring that the data entered into the system is valid. The following will be managed:
• Empty user input
• Invalid numeric input
• Invalid email addresses
• Invalid project IDs
• Invalid team members
• Full team capacity
• Duplicate applications

## Project Outcome

The end result of the project is a prototype of a Java application for student project collaboration. The application will be a platform that connects projects and potential team members. The prototype will enable students to create projects, find projects, apply to join projects, and manage tasks. The application’s design is modular and should therefore be possible to transform it into a database-driven and web-based collaboration platform.
